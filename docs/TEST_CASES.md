> **LƯU Ý VỀ TÍNH KHẢ THI & QUY TẮC SOURCE OF TRUTH DỮ LIỆU:**
> - **Stock Seed Scope:** `supabase/seed.sql` chỉ nạp danh mục catalog (`properties`, `rooms`, `room_operations`, `room_private_details`, và voucher definition `99999999-9999-9999-9999-999999999999`). File seed **không chứa** `auth.users`, `profiles`, `voucher_redemptions`, `checkout_sessions`, `bookings`, `booking_access_credentials`, hay `tickets`.
> - **Trạng thái thực thi trung thực:** Các test case chỉ được đánh dấu `READY` nếu dữ liệu có sẵn ngay sau `npx supabase db reset`. Những kịch bản yêu cầu dữ liệu giao dịch hoặc tài khoản xác thực đều ghi rõ trạng thái phụ thuộc (`REQUIRES AUTH ACCOUNT`, `REQUIRES BOOKING FIXTURE`, `REQUIRES ACTIVE STAY FIXTURE`, v.v.).
> - **QA Benchmark vs. Production Integration:** Local WebP assets (`/images/rooms/room-*.webp`) chỉ dùng để benchmark tài nguyên cục bộ; catalog phòng thực tế đang dùng URL Unsplash (`PENDING production integration`). Video hiện ở trạng thái `PENDING / TBD`.
